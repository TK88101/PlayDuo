## 1. 目標と非目標
### 目標
1. A01 管理者ログイン `admin/login.php`／ログアウト `admin/logout.php`（POST）
2. A02 管理メニュー `admin/index.php`（3 カード）
3. A03 商品一覧 `admin/products.php`、A04/A05 非公開・再公開の確認と実行 `admin/product_visibility.php?id=`
4. A06/A06-a 商品登録・編集 `admin/product_edit.php[?id=]`、A07 確認＋保存 `admin/product_confirm.php`（画像 4 枚・配布 ZIP のアップロード）
5. A08 会員一覧（検索）`admin/members.php`、A09 会員詳細 `admin/member.php?id=`
6. A10 注文一覧（期間・会員・商品で検索）`admin/orders.php`、A11 注文詳細 `admin/order.php?id=`
7. 共通：`includes/admin_header.php`・`admin_footer.php`、`includes/admin_auth.php`（require_admin）

### 非目標
- CSS・JS（吉松）。画面の「ダイアログ」は JS なしの確認画面（同じ HTML 構造の重ね表示用 class だけ付ける）
- 管理者アカウントの追加・変更画面（仕様に無い）、会員・注文の編集・削除（参照のみ：A08-013・A11-008）
- ページング（商品 8・会員 5・注文 5 程度。件数増加時の課題として残す）
- 商品の物理削除（論理削除＝非公開のみ）
